# 🥛 Dairy Sales Analysis | Power BI Project

## 📘 Project Overview
This Power BI project provides an in-depth **analysis of dairy sales and production data** to uncover performance trends, regional insights, and sales growth opportunities.  
The report consists of **five interactive pages** — Overview, Production, Sales, Sales Overview, and Stock — to support **data-driven decision-making** across multiple business areas.

---

## 🎯 Objectives
- Clean and transform raw dairy sales data using **Power Query Editor**  
- Build an interactive and multi-page Power BI dashboard  
- Identify **top-performing products, regions, and production trends**  
- Provide **sales and stock insights** for better planning and forecasting  

---

## 🗂️ Dataset Information
- **Source:** [Dairy Goods Sales Dataset – Kaggle](https://www.kaggle.com/datasets/suraj520/dairy-goods-sales-dataset)  
- **Description:** The dataset includes the following details:  
  - Product Name  
  - Category  
  - Quantity Sold  
  - Quantity Produced  
  - Unit Price  
  - Total Sales  
  - Region / State  
  - Date of Sale  

---

## 🔧 Data Preparation (Power Query Editor)
Data preprocessing and transformation were performed in **Power Query Editor**:
- Removed duplicates and corrected data types  
- Filtered unnecessary records  
- Added calculated columns (e.g., **Total Sales = Quantity × Unit Price**)  
- Ensured accuracy and consistency before visualization

## 💡 Key Insights
- **Delhi** and **Chandigarh** lead in both revenue and production quantity.  
- **Curd, Lassi, and Butter** are among the top three products by value.  
- Sales and production show seasonal variations throughout the year.  
- The interactive filters allow detailed exploration of state-wise and product-wise performance.
